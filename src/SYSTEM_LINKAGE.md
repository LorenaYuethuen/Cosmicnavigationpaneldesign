# 🌌 系统联动功能说明

## 概述

Lorena Manifestation OS V2.0 现已实现完整的模块间数据联动和智能分析功能。所有6个核心模块通过**统一状态管理系统（LifeSystemContext）**深度连接，实现了真正的生活系统矩阵。

---

## 🔗 核心联动架构

### 统一状态管理中心
**文件**: `/contexts/LifeSystemContext.tsx`

提供全局数据存储和跨模块通信：
- ✅ 能量扫描状态（currentEnergy）
- ✅ 显化意图列表（intentions）
- ✅ 阿卡西日志记录（logs）
- ✅ 身体频率运动记录（workouts）
- ✅ 三年路径目标（yearGoals）
- ✅ 系统综合统计（stats）

## 📊 六大模块联动关系

### 1️⃣ 显化面板 ↔ 能量扫描

**联动方式**：
- 能量扫描结果会显示在显化面板标题下方
- 创建意图时会记录当时的能量状态
- 根据当前能量等级调整建议的行动计划

**实现代码**：
```typescript
// ManifestationEngine.tsx
const { currentEnergy, addIntention } = useLifeSystem();

// 创建意图时关联能量
addIntention({
  text: newIntention,
  area: selectedArea,
  status: 'active',
  energyWhenCreated: currentEnergy // 关联能量状态
});
```

**用户体验**：
- 高能状态下设定的意图会被标记为"高能意图"
- 低能状态会提示延后设定重大意图
- 能量状态徽章动态显示在界面上

---

### 2️⃣ 能量扫描 ↔ 系统总览

**联动方式**：
- 能量扫描结果自动记录到能量历史
- 系统总览显示7天能量趋势（上升/稳定/下降）
- 平均能量值影响系统健康度评分

**数据流**：
```
能量扫描 → setCurrentEnergy() 
  → energyHistory更新 
  → 系统总览计算趋势和平均值
  → 生成智能洞察
```

**智能洞察示例**：
- "🌟 你处于高能量周期，适合推进重要项目和目标"
- "🌙 你需要更多休息和滋养，温柔对待自己"
- "⚖️ 能量波动正常，保持平衡的生活节奏"

---

### 3️⃣ 阿卡西日志 ↔ 能量扫描

**联动方式**：
- 每条日志记录时会标注能量等级
- 日志中的能量数据会同步到能量历史
- 系统统计显示高/中/低能天数分布

**连续性追踪**：
```typescript
stats.currentStreak // 连续记录天数
```

**建议联动**：
- 连续记录7天+：显示"🔥 保持火热"徽章
- 连续记录0天：智能建议"开始今日的阿卡西日志记录"

---

### 4️⃣ 身体频率 ↔ 系统总览

**联动方式**：
- 运动记录影响系统健康度评分
- 本周运动次数影响智能建议
- 运动频率与能量等级相关联

**目标追踪**：
```typescript
weeklyWorkoutTarget = 4 // 每周4次目标
workoutProgress = (stats.weeklyWorkouts / 4) * 100
```

**智能建议**：
- 运动次数 < 3：建议增加运动
- 高能日：推荐高强度训练（力量、攀岩）
- 低能日：推荐轻度运动（散步、瑜伽）

---

### 5️⃣ 三年路径 ↔ 显化面板

**联动方式**：
- 年度目标可以转化为具体意图
- 显化引擎追踪长期目标的短期进度
- 季度里程碑完成度影响系统评分

**未来增强**（计划中）：
- 自动将年度目标分解为月度/周度意图
- 进度可视化关联显化引擎
- 完成度自动更新三年路径进度条

---

### 6️⃣ 系统总览 - 全局智能中枢

**核心功能**：

#### A. 系统健康度评分
```typescript
getSystemHealth(): 'excellent' | 'good' | 'needsAttention' | 'critical'
```

评分因素（总分100）：
- 运动频率：30分
- 日志连续性：30分
- 意图完成率：30分
- 平均能量值：10分

#### B. 智能建议引擎
```typescript
getSuggestedActions(): string[]
```

根据以下因素生成个性化建议：
- ✅ 当前能量等级
- ✅ 本周运动次数
- ✅ 日志记录连续性
- ✅ 意图完成度

**建议示例**：
```javascript
[
  "完成一个显化意图中的重要任务",
  "本周运动次数不足，考虑增加运动",
  "已连续记录7天，保持下去！",
  "关注显化引擎中的活跃意图，采取行动"
]
```

#### C. 能量洞察分析
```typescript
getEnergyInsights(): string
```

分析最近7次能量记录，生成趋势洞察。

## 📈 数据统计面板

### 核心指标卡片
```typescript
interface SystemStats {
  totalIntentions: number;        // 总意图数
  completedIntentions: number;    // 已完成意图
  totalLogs: number;              // 总日志数
  averageEnergy: number;          // 平均能量（0-3）
  weeklyWorkouts: number;         // 本周运动次数
  currentStreak: number;          // 连续记录天数
}
```

### 实时计算
- **活跃意图**: `totalIntentions - completedIntentions`
- **意图完成率**: `(completedIntentions / totalIntentions) * 100`
- **本周运动进度**: `(weeklyWorkouts / 4) * 100`
- **能量趋势**: 基于最近7次记录

## 🌟 智能联动特性

### 1. 自适应建议
根据用户的实时状态提供个性化建议，而非固定内容。

### 2. 跨模块数据同步
一个模块的数据变化会立即反映到其他相关模块。

### 3. 趋势分析
系统会分析7天、14天的数据，识别上升/稳定/下降趋势。

### 4. 健康度预警
当系统健康度低于阈值时，会自动提醒用户关注。

### 5. 连续性激励
连续记录7天、14天会有特殊徽章和鼓励。

## 📚 技术实现要点

### Context Provider 结构
```typescript
<LifeSystemProvider>
  <App>
    <LifeSystemPage>
      <ManifestationEngine />  // 消费 intentions
      <EnergyScanButton />     // 消费 setCurrentEnergy
      <AkashicLogger />        // 消费 logs, addLog
      <BodyFrequency />        // 消费 workouts
      <ThreeYearPath />        // 消费 yearGoals
      <SystemDashboard />      // 消费 stats, 智能函数
    </LifeSystemPage>
  </App>
</LifeSystemProvider>
```

### 数据流向
```
用户操作 
  → 调用 Context 函数 
  → 更新全局状态 
  → 触发相关组件重渲染 
  → 智能函数重新计算 
  → UI 显示最新数据
```
