# 🔗 系统联动功能完整清单

## ✅ 已实现的联动功能

### 1️⃣ 显化面板 (Manifestation Engine)

#### 联动输入
- **接收能量扫描数据**
  - 显示当前能量状态徽章
  - 创建意图时自动关联能量等级
  - `energyWhenCreated` 字段记录意图创建时的能量状态

#### 联动输出
- **提供意图给阿卡西日志**
  - 新建日志时自动建议活跃意图作为今日动作
  - 显示"已关联X个活跃意图"徽章
  
- **提供统计给系统总览**
  - 活跃意图数量
  - 已完成意图数量
  - 意图完成率影响系统健康度（30分权重）

#### 实际效果
```typescript
// 用户完成能量扫描 → 显示"当前能量：high"
// 创建意图 → 记录 energyWhenCreated: 'high'
// 系统总览 → 显示活跃意图卡片：3个活跃
```

### 2️⃣ 能量扫描 (Energy Scan)

#### 联动输入
- 无（作为数据源头）

#### 联动输出
- **更新全局能量状态**
  - `currentEnergy` 全局可访问
  - 自动记录到 `energyHistory` 数组

- **影响显化面板**
  - 高能日：建议设定重要意图
  - 低能日：提示延后重大决策

- **影响阿卡西日志**
  - 新建日志时自动填充当前能量等级
  - 显示"当前能量：高能"徽章

- **影响身体频率**
  - 高能/创造：建议高强度训练
  - 中能/重启：建议常规训练
  - 低能/低池：建议轻度运动
  - 崩溃：建议休息为主

- **影响系统总览**
  - 7天能量趋势分析（上升/稳定/下降）
  - 平均能量值影响健康度评分（10分权重）
  - 智能洞察：高能周期提示、低能周期关怀

#### 实际效果
```typescript
// 扫描结果：高能日
// ↓
// 显化面板：显示"当前能量：high"徽章
// 阿卡西日志：自动填充"高能"状态
// 身体频率：显示"适合高强度训练"
// 系统总览：能量趋势"上升"，建议"推进重要项目"
```

### 3️⃣ 阿卡西日志 (Akashic Logger)

#### 联动输入
- **接收能量扫描数据**
  - 新建日志时自动填充当前能量
  - 显示当前能量状态徽章

- **接收显化意图数据**
  - 活跃意图自动建议为今日动作
  - 显示"已关联X个活跃意图"提示

#### 联动输出
- **同步能量历史**
  - 日志中的能量等级自动添加到 `energyHistory`
  - 双向数据同步确保一致性

- **提供统计给系统总览**
  - 总日志数
  - 连续记录天数（currentStreak）
  - 连续性影响健康度评分（30分权重）
  - 高/中/低能天数分布统计

#### 实际效果
```typescript
// 点击新建日志
// ↓
// 自动填充：能量="high"（来自扫描）
// 自动建议：动作=["力量训练", "完成项目"]（来自意图）
// 保存后
// ↓
// 系统总览：连续天数+1，显示"🔥保持火热"

```

### 6️⃣ 系统总览 (System Dashboard)

#### 联动输入
- **汇总所有模块数据**
  - 能量扫描：currentEnergy, energyHistory
  - 显化面板：intentions, 完成率
  - 阿卡西日志：logs, 连续天数
  - 身体频率：workouts, 本周次数
  - 三年路径：yearGoals

#### 核心功能

##### A. 系统健康度评分（100分制）
```typescript
运动频率（30分）：
  - ≥4次/周 → 30分
  - ≥3次/周 → 20分
  - ≥2次/周 → 10分

日志连续性（30分）：
  - ≥14天 → 30分
  - ≥7天 → 20分
  - ≥3天 → 10分

意图完成率（30分）：
  - ≥60% → 30分
  - ≥40% → 20分
  - ≥20% → 10分

平均能量值（10分）：
  - ≥2.5 → 10分
  - ≥2.0 → 7分
  - ≥1.5 → 4分

总分 ≥80 → Excellent ⭐
总分 ≥60 → Good ✅
总分 ≥40 → Needs Attention ⚠️
总分 <40  → Critical 🔴
```

##### B. 智能建议引擎
```typescript
基于能量等级：
  - high/create → "完成重要任务" + "高强度运动"
  - low/lowpool → "轻度运动" + "休息滋养"
  - crash → "取消计划" + "寻求支持"

基于运动频率：
  - <3次/周 → "本周运动次数不足，考虑增加运动"

基于日志连续性：
  - 0天 → "开始今日的阿卡西日志记录"
  - ≥7天 → "已连续记录X天，保持下去！"

基于意图完成率：
  - <30% → "关注显化引擎中的活跃意图，采取行动"
```

##### C. 能量洞察分析
```typescript
最近7次能量记录分析：
  - ≥5次高能 → "🌟 你处于高能量周期，适合推进重要项目"
  - ≥5次低能 → "🌙 你需要更多休息和滋养，温柔对待自己"
  - 其他 → "⚖️ 能量波动正常，保持平衡的生活节奏"
```

##### D. 核心指标卡片
```typescript

2. 连续记录天数：≥7天显示"🔥保持火热"徽章
3. 本周运动：X/4 + 进度条
4. 平均能量：实时计算 + 趋势箭头（↗↘→）
```

## 🎯 具体联动场景

### 场景1：高效的一天
```
1. 早晨 8:00
   用户：启动能量扫描
   系统：识别为"高能日" → 设置currentEnergy='high'
   
2. 早晨 8:05
   显化面板：显示"当前能量：高能"徽章
   系统总览：智能建议"完成重要任务" + "高强度运动"
   
3. 上午 10:00
   用户：在显化面板设定意图"完成项目设计"
   系统：记录 energyWhenCreated='high'
   
4. 下午 17:00
   用户：记录力量训练60分钟
   系统：本周运动3/4 → 进度75%
   
5. 晚上 21:00
   用户：新建阿卡西日志
   系统：自动填充 energy='high'
   系统：自动建议 actions="完成项目设计"（来自意图）
   用户：保存日志
   系统：连续天数+1 → 7天 → 显示"🔥保持火热"
   
6. 晚上 21:05
   系统总览：
   - 健康度：Good → Excellent（因运动+日志+意图完成）
   - 能量趋势：↗ 上升
   - 智能建议："已连续记录7天，保持下去！"
```

### 场景2：需要休养的一周
```
1. 周一：能量扫描 → low
   系统：建议"轻度运动" + "温柔对待自己"
   
2. 周二：能量扫描 → lowpool
   系统：建议"休息为主" + "取消非必要活动"
   
3. 周三：能量扫描 → crash
   系统：建议"暂停所有计划" + "寻求支持"
   身体频率：显示"建议休息为主"
   
4. 周四：用户记录瑜伽30分钟（低强度）
   系统：本周运动1/4 → 进度25%
   系统总览：提示"本周运动次数不足"
   
5. 周五：用户未记录日志
   系统：连续天数归零
   
6. 周日：系统总览
   - 健康度：Needs Attention ⚠️
   - 能量洞察："🌙 你需要更多休息和滋养"
   - 智能建议：
     * "温柔对待自己，减少压力"
     * "本周运动次数不足"
     * "开始今日的阿卡西日志记录"
```
